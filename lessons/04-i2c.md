# Lesson 04 — I²C from registers

Status: planned. Prerequisite: UART debugging.

Goal: communicate with the AS5600 using your own driver instead of Arduino's `Wire` library.

I²C uses SDA for data and SCL for the clock. The Mega initiates a transaction and the sensor responds. We will use the ATmega2560's hardware interface, called TWI in its documentation.

We will cover device addresses versus register addresses, START/STOP conditions, reads and writes, acknowledgments, repeated START, status codes, and timeouts.

Exercise: implement and inspect a sensor-register read. Verify the exact address, register layout, and byte order from the device documentation before coding them.

Class workspace: `src/drivers/I2cMaster.h`.

Review checkpoint: explain the sequence of a register read and how your driver reports a missing device. Keep motor power disconnected.
